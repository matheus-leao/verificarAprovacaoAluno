# Objetivo: 
Crie uma skill responsavel por Avaliar um requisito ou problema, e propor cenários de teste utilizando uma das estratégias listadas na pasta tecnicas de teste. Sempre ao executar você deve perguntar qual técnica o usuário quer executar (analise do valor limite, partição de equivalência, test-charter)

# Contexto:
- O resultado da skill deve ser uma lista de cenários de teste ou casos de teste para serem executados, descreva de uma forma clara para que possamos automatizá-lo depois.
- Após cada execução você deve perguntar ao usuário se ele quer alguma alteração entre os cenários, como remover um cenário que não faz sentido ou adicionar mais cenários importantes

# Regras:
- Sempre crie to-do list para deixar claro em qual passo da skill você está executando.
- Cada técnica de teste tem seus detalhes descritos em seus respectivos arquivos, use esses detalhes para tomar decisões e utilizá-la. 

# Output: 
- Após a aprovado adicione uma opção para que possa exportar os cenários para arquivos .md ou para arquivos .xlsx
